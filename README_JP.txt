=====================================================
 Native Lang — DeepL 設定ガイド
 アドオン v1.1.5  /  翻訳エンジン v0.0.7
=====================================================

同梱ファイル:
   native_lang-v1.1.5.ipf
   native_lang-v0.0.7.exe


--- STEP 0: 先に古いバージョンを削除してください (重要) ---

以前の Native Lang を導入済みの場合は、<ゲームフォルダ>\data\ にある
古い .ipf を先に削除してください。次のような名前です:

   _native_lang-<なにか>-v1.1.4.ipf

残したままだとアドオンが二重に読み込まれ、正常に動作しません。

<ゲームフォルダ>\addons\native_lang\ にある古い
native_lang-v0.0.x.exe / .tar も削除して構いません（もう使いません）。


--- STEP 1: DeepL の無料 API キーを取得する ---

1. こちらにアクセス:  https://www.deepl.com/pro-api
   「Free API Key」ボタンをクリックします。

   !! 重要 !!
   必ず「DeepL API Free」(開発者向けプラン) に登録してください。
   通常の DeepL Pro 翻訳サブスクリプションでは API キーは
   発行されません。ここを間違える方が非常に多いです。

2. 登録後、こちらでキーを確認できます:
      https://www.deepl.com/your-account/keys
   (アカウント →「API Keys」タブ)

3. 無料キーは末尾が ":fx" になっています:
      279a2e9d-83b3-c416-7e2d-f721593e42a0:fx

   無料プランの上限: 月 1,000,000 文字
   (2026-09-16 に DeepL の /v2/usage エンドポイントで確認済み)
   登録時の必要事項は地域により異なる場合があるため登録ページでご確認ください。


--- STEP 2: 2 つのファイルを配置する ---

   native_lang-v1.1.5.ipf   ->   <ゲームフォルダ>\data\
   native_lang-v0.0.7.exe   ->   <ゲームフォルダ>\addons\native_lang\

   「addons\native_lang」フォルダが無い場合は作成してください。

   ※ ウイルス対策ソフトが .exe を脅威として誤検出することがあります。
     その場合は addons\native_lang フォルダを除外設定に追加してください。

   配置したらゲームを起動します。


--- STEP 3: ゲーム内でキーを入力する ---

1. チャットウィンドウを見てください。チャットタブの隣に、言語コード
   (例:「ja」) が表示された小さな四角いボタン (30x30) があります。

2. 左クリックすると「Native Lang」メニューが開きます。

3. 次の行をクリック:
      DeepL API Key : OFF (Google)

4. ウィンドウが開きます:
      「DeepL APIキーを入力してください（deepl.com/pro-apiで無料取得）」
   入力欄にキーを貼り付けてください。

5. [ 保存して再起動 ] をクリック
   「DeepL APIキーを保存しました。再起動します。」と表示されます。

6. もう一度メニューを開くと、次のように変わっています:
      DeepL API Key : ON        (緑色)

これで完了です。チャットとプレイヤー名が DeepL で翻訳されます。


--- 別の方法: ファイルを直接編集する ---

   <ゲームフォルダ>\addons\native_lang\<アカウントID>\settings.json

   "deepl_api_key" の値を設定します:
      {"use":1,"lang":"ja","recv_lang":"en","chatmode":false,
       "deepl_api_key":"ここにキー:fx"}

   翻訳エンジンはこのファイルを 1 秒ごとに読み直すため、
   ゲームの再起動は不要です。


--- 補足 ---

* キーが無い場合は Google 翻訳にフォールバックします。ただし Google の
  無料エンドポイントは、リクエストが多い IP アドレスを遮断します
  (「unusual traffic」/ HTTP 429)。このアドオンはチャット 1 行につき
  1 リクエストを送るため、DeepL キーの使用を強く推奨します。
* Google に戻したい場合は、同じウィンドウの [ クリア(Google) ] を
  クリックしてください。
* キーはご自身のアカウントフォルダにのみ保存され、アドオン本体
  (.ipf) には一切含まれません。
* その他のメニュー項目:「アドオンストップ」で翻訳を停止、
  「チャットモードへ切替」でチャットのみ翻訳 (名前は翻訳しない)、
  「アドオン再起動」で翻訳エンジンを再起動します。


--- 動作しない場合 ---

次の順に確認してください:

1. native_lang-v0.0.7.exe が起動していますか？ (タスクマネージャー)
   起動していない場合: ウイルス対策ソフトに削除されたか、
   ファイル名が違う可能性があります。
2. addons\native_lang\ に restart.dat が残っていませんか？
   残っていると翻訳エンジンが自分で終了してしまいます。削除してください。
3. addons\native_lang\ の *.processing / *.tmp ファイルを削除してください。
4. チャットタブ横のボタンは赤 (動作中) ですか、灰色 (停止中) ですか？
   灰色なら停止中です。クリックして「アドオン起動」を選んでください。
