## 🇰🇷 한국어

### 이번 업데이트 (v1.2.4)

- **인던 패널: 고고학 아이콘 추가**
  좌클릭으로 고고학 유물 상점을 어디서나 열고, 우클릭으로 클라페다의 고고학자 아이리네에게 이동합니다.
  설정창의 아이콘 체크박스로 끌 수 있습니다.

- **Archeology Helper: 개편된 고고학에 맞춰 수정**
  - 탐지기 거리 7단계를 모두 지도에 색 원으로 표시합니다(가장 가까운 단계가 표시되지 않던 문제 수정).
  - 탐지 횟수(사용/최대), 찾은 지점(x/4), 유물 탐사 허가증 보유 수를 표시합니다.
  - 의뢰 수락·완료에 맞춰 자동으로 초기화되고 접힙니다.

### 설치 방법
- **옛 nexus_addons 의 ipf 파일만 삭제**하고 이 애드온을 넣어 주세요.
- 또는 addon manager 에서 update 해 주세요.

## 🇺🇸 English

### What's new in v1.2.4

- **Dungeon panel: new archaeology icon**
  Left-click opens the archaeology relic shop from anywhere; right-click moves you to Archaeologist Airine in Klaipeda.
  You can hide it with the icon checkboxes in the panel settings.

- **Archeology Helper: updated for the reworked archaeology**
  - All seven detector distance levels are drawn as coloured circles on the map (the closest levels were not shown before).
  - Shows detector uses (used / max), points found (x/4) and dig permits held.
  - Resets and folds automatically when you accept or finish a mission.

### How to install
- **Delete only the old nexus_addons ipf file** and add this addon.
- Or update from the addon manager.

## 🇯🇵 日本語

### 今回の更新 (v1.2.4)

- **インダンパネル: 考古学アイコンを追加**
  左クリックで考古学遺物ショップをどこでも開き、右クリックでクラペダの考古学者アイリーネへ移動します。
  設定画面のアイコンのチェックで非表示にできます。

- **Archeology Helper: リニューアルされた考古学に対応**
  - 探知機の距離7段階をすべてマップに色付きの円で表示します(一番近い段階が表示されなかった問題を修正)。
  - 探知回数(使用/最大)、見つけた地点(x/4)、遺物探査許可証の所持数を表示します。
  - 依頼の受諾・完了に合わせて自動でリセットされ、折りたたまれます。

### インストール方法
- **古い nexus_addons の ipf ファイルだけを削除**して、このアドオンを入れてください。
- または addon manager から update してください。
