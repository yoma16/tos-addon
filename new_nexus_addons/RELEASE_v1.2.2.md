## 🇰🇷 한국어

### 이번 업데이트 (v1.2.2)

- **Lv.560 챌린지 입장권: 가지고 있는 것부터 씁니다**
  v1.1.9 에서 용병단증표 버튼만 구매를 1순위로 바꿨었는데, 인벤토리에 기간제 입장권이
  있어도 새로 사서 쓰는 문제가 있었습니다. 기간제는 놔두면 사라지므로 아껴도 소용이 없습니다.
  이제 Lv.560 의 두 버튼(TOS 코인 / 용병단증표)이 같은 순서로 동작합니다.

  `1. 기간제 → 2. 거래불가 → 3. 입장권 구매 → 4. 무기한(거래가능)`

  Lv.540 은 예전 그대로입니다.

- 두 버튼의 **툴팁도 순서에 맞게 고쳤습니다**. TOS 코인 쪽 툴팁에 빠져 있던 "거래불가"
  단계도 채웠습니다.

### 설치 방법
- **옛 nexus_addons 의 ipf 파일만 삭제**하고 이 애드온을 넣어 주세요.
- 또는 addon manager 에서 update 해 주세요.

## 🇺🇸 English

### What's new in v1.2.2

- **Lv.560 challenge tickets: what you already hold comes first**
  v1.1.9 made the mercenary-badge button buy first, but that meant a new ticket was bought
  while an expiring one sat in your bag. An expiring ticket is lost if you do not use it,
  so there is nothing to save it for. Both Lv.560 buttons (TOS coin / mercenary badge) now
  follow the same order.

  `1. Expiring → 2. Untradable → 3. Buy a ticket → 4. Permanent (tradable)`

  Lv.540 is unchanged.

- Both **tooltips were rewritten to match**, and the untradable step that was missing from
  the TOS-coin tooltip was added.

### How to install
- **Delete only the old nexus_addons ipf file** and add this addon.
- Or update from the addon manager.

## 🇯🇵 日本語

### 今回の更新 (v1.2.2)

- **Lv.560 チャレンジのチケット: 手持ちを先に使います**
  v1.1.9 で傭兵団証票のボタンだけ購入を最優先にしましたが、期限付きチケットを持っていても
  新しく買って使ってしまう問題がありました。期限付きは置いておくと消えるので、温存する
  意味がありません。Lv.560 の2つのボタン(TOS コイン / 傭兵団証票)が同じ順序になりました。

  `1. 期限付き → 2. 取引不可 → 3. チケット購入 → 4. 期限なし(取引可)`

  Lv.540 は従来どおりです。

- 2つのボタンの**ツールチップも順序に合わせて修正**しました。TOS コイン側に抜けていた
  「取引不可」の段階も補いました。

### インストール方法
- **古い nexus_addons の ipf ファイルだけを削除**して、このアドオンを入れてください。
- または addon manager から update してください。
