## 🇰🇷 한국어

### 이번 업데이트 (v1.2.1)

- **우리엘 하드(파티)에서도 물약을 자동으로 바꿔줍니다**
  v1.2.0 에서 파티 난이도를 인던 패널에 추가했지만, 레이드별 물약 교체 표에는 자동 매칭과
  1인 입장만 들어 있었습니다. 그래서 하드로 들어가면 물약이 그대로였습니다.
  두 보스 모두 다른 난이도와 같은 종족이라, 빠져 있던 두 개를 채웠습니다.

### v1.2.0 에 들어간 것

- **Lv.540 분열: "4인 이하 입장" 자동 동의** — Lv.540 에만 적용되고 Lv.560 은 그대로입니다.
  인던 패널 설정창의 **기타** 에서 끌 수 있습니다(기본 켜짐).
- **우리엘 하드(파티) 레이드 추가** — 인던 패널의 **H 버튼**과 캐릭터별 인던 목록의
  **Hard 칸**.

### 설치 방법
- **옛 nexus_addons 의 ipf 파일만 삭제**하고 이 애드온을 넣어 주세요.
- 또는 addon manager 에서 update 해 주세요.

## 🇺🇸 English

### What's new in v1.2.1

- **The raid potion swap now covers the Uriel hard (party) tier**
  v1.2.0 added the party difficulty to the dungeon panel, but the per-raid potion table only
  listed the auto-match and solo entries, so going in on hard kept whatever potions were on
  the bar. Both bosses are the same race as their other difficulties, so the two missing
  entries were all it needed.

### What v1.2.0 brought

- **Lv.540 Singularity: understaffed entry is agreed to for you** — Lv.540 only; Lv.560 is
  untouched. Turn it off in the panel settings under **Other** (on by default).
- **Uriel hard (party) raids added** — the **H button** in the dungeon panel and their
  **Hard columns** in the per-character dungeon list.

### How to install
- **Delete only the old nexus_addons ipf file** and add this addon.
- Or update from the addon manager.

## 🇯🇵 日本語

### 今回の更新 (v1.2.1)

- **ウリエルのハード(パーティ)でも薬を自動で切り替えます**
  v1.2.0 でパーティ難易度をインダンパネルに追加しましたが、レイドごとの薬の切り替え表には
  自動マッチングとソロしか入っていませんでした。そのためハードで入ると薬がそのままでした。
  どちらのボスも他の難易度と同じ種族なので、抜けていた2つを補いました。

### v1.2.0 の内容

- **Lv.540 分裂: 「4人以下入場」に自動で同意** — 適用は Lv.540 のみで Lv.560 はそのままです。
  インダンパネル設定の**「その他」**からオフにできます(初期状態オン)。
- **ウリエルのハード(パーティ)レイドを追加** — インダンパネルの **Hボタン**と、
  キャラクター別インダン一覧の **Hard欄**。

### インストール方法
- **古い nexus_addons の ipf ファイルだけを削除**して、このアドオンを入れてください。
- または addon manager から update してください。
