## 🇰🇷 한국어

### 이번 업데이트 (v1.2.5)

- **세이브 퀘스트: 퀘스트를 포기하면 바로가기도 해제됩니다**
  지금까지는 포기해도 화면의 바로가기가 남아 있었습니다.

- **세이브 퀘스트: 2026-11-03 KR 클라이언트 업데이트 대응**
  최신 클라이언트에서는 서버가 포기를 확정했을 때만 저장을 해제합니다. 포기가 거절되면 저장은 그대로 남습니다.

### 설치 방법
- **옛 nexus_addons 의 ipf 파일만 삭제**하고 이 애드온을 넣어 주세요.
- 또는 addon manager 에서 update 해 주세요.

## 🇺🇸 English

### What's new in v1.2.5

- **Save Quest: abandoning a quest now also clears its shortcut**
  Until now the shortcut stayed on screen after the quest was abandoned.

- **Save Quest: updated for the 2026-11-03 KR client**
  On the latest client the save is cleared only after the server confirms the abandon. If the abandon is refused, the save stays.

### How to install
- **Delete only the old nexus_addons ipf file** and add this addon.
- Or update from the addon manager.

## 🇯🇵 日本語

- **セーブクエスト: クエストを放棄するとショートカットも解除されます**
  これまでは放棄してもショートカットが画面に残っていました。
