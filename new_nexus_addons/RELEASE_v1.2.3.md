## 🇰🇷 한국어

### 이번 업데이트 (v1.2.3)

- **인던 패널: 공명의 성소 입장이 안 되던 문제 수정**
  v1.1.7 부터 입장 버튼을 누르면 단계 선택 창은 뜨지만, 그 창에서 입장을 눌러도
  들어가지지 않았습니다. 이제 단계 선택 창에서 단계를 골라 정상적으로 입장할 수 있습니다.

- **배럭 아이템 검색: 개인창고 아이템이 검색되지 않던 문제 수정**
  개인창고를 닫아도 내용이 저장되지 않아, 개인창고에 넣어 둔 아이템은 검색에 나오지
  않았습니다. 이제 개인창고를 한 번 열었다 닫으면 그 캐릭터의 창고 아이템이 검색됩니다.

### 설치 방법
- **옛 nexus_addons 의 ipf 파일만 삭제**하고 이 애드온을 넣어 주세요.
- 또는 addon manager 에서 update 해 주세요.

## 🇺🇸 English

### What's new in v1.2.3

- **Dungeon panel: fixed entering the Sanctuary of Resonance**
  Since v1.1.7 the entry button opened the step-selection window, but pressing enter there
  did nothing. You can now pick a step in that window and enter normally.

- **Character item search: personal warehouse items were never found**
  Closing the personal warehouse did not save its contents, so items stored there never showed
  up in the search. Open and close the warehouse once and that character's items become searchable.

### How to install
- **Delete only the old nexus_addons ipf file** and add this addon.
- Or update from the addon manager.

## 🇯🇵 日本語

### 今回の更新 (v1.2.3)

- **インダンパネル: 共鳴の聖所に入場できなかった問題を修正**
  v1.1.7 から入場ボタンを押すと段階選択ウィンドウは開くものの、そこで入場を押しても
  入れませんでした。段階選択ウィンドウで段階を選んで正常に入場できるようになりました。

- **キャラクターアイテム検索: 個人倉庫のアイテムが検索できなかった問題を修正**
  個人倉庫を閉じても内容が保存されず、個人倉庫に入れたアイテムは検索に出てきませんでした。
  倉庫を一度開いて閉じると、そのキャラクターの倉庫アイテムが検索できるようになります。

### インストール方法
- **古い nexus_addons の ipf ファイルだけを削除**して、このアドオンを入れてください。
- または addon manager から update してください。
