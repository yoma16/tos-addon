## 🇰🇷 한국어

### 이번 업데이트 (v1.2.7)

- **CCH: 세트를 꺼낸 뒤 카드 우클릭 장착이 막히던 문제 수정**
  창고 자동 닫기를 켜 두면 작업이 끝난 뒤 창고 창이 화면에 남고, 인벤에서 카드를 우클릭해도 장착되지 않았습니다(ESC 를 여러 번 눌러야 풀림).
  이제 창고 창이 제대로 닫힙니다.
- **인던 패널: 4인 이하 입장 자동 동의 범위 확대**
  540 분열만 → 540·560 분열, 560 챌린지(파티) 자동매칭 전부. 켜 둔 설정은 그대로 유지되며, 설정 이름과 동의 알림에 인던 이름이 표시됩니다.

### 설치 방법
- **옛 nexus_addons 의 ipf 파일만 삭제**하고 이 애드온을 넣어 주세요.
- 또는 addon manager 에서 update 해 주세요.

## 🇺🇸 English

### What's new in v1.2.7

- **CCH: fixed right-click card equip being blocked after taking a set**
  With the auto warehouse close on, the warehouse window stayed on screen after the operation and right-clicking a card in the inventory did not equip it (only pressing ESC several times fixed it).
  The warehouse window now closes properly.
- **Indun Panel: understaffed-entry auto-allow covers more dungeons**
  540 Singularity only → every auto-match entry: 540 / 560 Singularity and 560 Challenge (party). Your saved setting is kept; the setting label and the confirmation message now name the dungeon.

### How to install
- **Delete only the old nexus_addons ipf file** and add this addon.
- Or update from the addon manager.

## 🇯🇵 日本語

### 今回の更新 (v1.2.7)

- **CCH: セット搬出後にカードの右クリック装着ができなかった問題を修正**
  倉庫自動クローズをオンにしていると、作業後に倉庫ウィンドウが画面に残り、インベントリでカードを右クリックしても装着されませんでした(ESC を何度か押すと解除)。
  倉庫ウィンドウが正しく閉じるようになりました。
- **インダンパネル: 4人以下入場の自動同意の範囲を拡大**
  540分裂のみ → 540・560分裂、560チャレンジ(パーティ)の自動マッチング全部。オンにしていた設定はそのまま残り、設定名と同意メッセージにインダン名が表示されます。

### インストール方法
- **古い nexus_addons の ipf ファイルだけを削除**して、このアドオンを入れてください。
- または addon manager から update してください。
