## 🇰🇷 한국어

### 이번 업데이트 (v1.2.8)

- **11/10 KR 패치 대응: 팀 창고 자동 넣기 수정**
  패치 이후 팀 창고에 자동으로 넣는 기능이 서버에서 거부되어 동작하지 않았습니다.
  아래 기능이 다시 정상적으로 넣어집니다.
  - AWH: 자동 넣기, 우클릭 넣기, Shift+우클릭 개수 지정 넣기
  - CCH: 세트·젬·카드 넣기
  - 몬스터 카드 교체: 창고에 넣기

### 설치 방법
- **옛 nexus_addons 의 ipf 파일만 삭제**하고 이 애드온을 넣어 주세요.
- 또는 addon manager 에서 update 해 주세요.

## 🇺🇸 English

### What's new in v1.2.8

- **KR client update (2026-11-10): team warehouse deposits fixed**
  Since the update, automatic deposits into the team warehouse were rejected by the server and did nothing.
  The following deposit correctly again:
  - AWH: auto deposit, right-click deposit, Shift+right-click deposit with amount
  - CCH: set, gem and card deposit
  - Monster card changer: deposit to warehouse

### How to install
- **Delete only the old nexus_addons ipf file** and add this addon.
- Or update from the addon manager.

## 🇯🇵 日本語

### 今回の更新 (v1.2.8)

- **11/10 KR パッチ対応: チーム倉庫への自動預け入れを修正**
  パッチ以降、チーム倉庫への自動預け入れがサーバーに拒否され、動作していませんでした。
  以下の機能が再び正しく預け入れられます。
  - AWH: 自動預け入れ、右クリック預け入れ、Shift+右クリックの個数指定預け入れ
  - CCH: セット・ジェム・カードの預け入れ
  - モンスターカード交換: 倉庫への預け入れ

### インストール方法
- **古い nexus_addons の ipf ファイルだけを削除**して、このアドオンを入れてください。
- または addon manager から update してください。
