# Cupole Manager v1.0.2

> 트리 오브 세이비어 쿠폴(Cupole) 관리 애드온입니다. (제작: Yomae)
> 프리셋 저장/불러오기, 도시 진입 시 자동 소환, 퀵슬롯 스킬 동기화를 지원합니다.

## 🇰🇷 한국어

### 이번 업데이트 (v1.0.2)
- **화면에 항상 떠있는 프리셋 HUD 추가**
  - 선택창에 들어갈 필요 없이, **"Cupole Preset" 토글 바**의 on/off 버튼으로 저장된 프리셋 목록을 바로 열고 닫습니다.
  - 목록의 프리셋 이름을 클릭하면 **즉시 적용**되며, 적용 후에도 목록은 닫히지 않습니다.
  - 바는 **화면 오른쪽 끝**에 반투명하게 나타나며, **드래그로 위치 이동**이 가능합니다.
  - **표시 상태와 위치가 재접속 후에도 유지**됩니다.
  - HUD는 **마을(도시)에서만** 표시됩니다.
  - 넥서스 메뉴의 Cupole Preset 아이콘 **우클릭**으로도 HUD를 켜고 끌 수 있습니다.
- **기존 퀵 적용 팝업 창 제거** (HUD로 일원화)
- **프리셋 편집 창 개선**
  - Set Name 저장 시 상단 **탭 이름이 즉시 반영**됩니다 (창을 다시 열 필요 없음).
  - 기존 'Clear' 버튼을 **'Delete'로 변경** — 해당 프리셋을 완전히 삭제합니다.
  - 하단의 보유 쿠폴 목록 여백 등 레이아웃을 정리했습니다.

### 설치 방법
- 기존 `cupole_manager` ipf 파일을 삭제하고 이 애드온을 넣어주세요.
- 혹은 addon manager에서 update 하세요.

### 사용법
- **넥서스 메뉴의 Cupole Preset 아이콘 좌클릭** — 전체 프리셋 편집 창 열기 (프리셋 1~10 생성/저장)
- 오른쪽의 "Cupole Preset" 바 on/off 버튼 (또는 메뉴 아이콘 **우클릭**) — 프리셋 목록 열기/닫기
- 쿠폴 변경은 도시(마을)에서만 가능합니다.

## 🇺🇸 English

### What's New (v1.0.2)
- **Added an always-on-screen preset HUD**
  - No need to open a selection window — the **"Cupole Preset" toggle bar**'s on/off button opens and closes your saved preset list directly.
  - Click a preset name in the list to **apply it instantly**; the list stays open after applying.
  - The bar appears translucent at the **right edge of the screen** and can be **dragged** to reposition.
  - **Visibility and position persist across relog.**
  - The HUD **only appears in town**.
  - You can also **right-click** the Cupole Preset icon in the Nexus menu to toggle the HUD.
- **Removed the old quick-apply popup window** (unified into the HUD).
- **Preset editor improvements**
  - Saving a Set Name now **updates the top tab label instantly** (no need to reopen the window).
  - The old 'Clear' button is now **'Delete'** — it fully removes that preset.
  - Tidied the layout, including bottom spacing of the owned-Cupole list.

### How to Install
- Remove your old `cupole_manager` ipf file, then add this addon.
- Or update it from the addon manager.

### Usage
- **Left-click the Cupole Preset icon in the Nexus menu** — open the full preset editor (create/save presets 1–10).
- The on/off button on the right-side "Cupole Preset" bar (or **right-click** the Nexus menu icon) — open/close the preset list.
- Cupoles can only be changed while in town.

## 🇯🇵 日本語

### 今回のアップデート (v1.0.2)
- **画面に常時表示されるプリセットHUDを追加**
  - 選択ウィンドウを開かず、**「Cupole Preset」トグルバー**の on/off ボタンで保存済みプリセット一覧を直接開閉できます。
  - 一覧のプリセット名をクリックすると**即座に適用**され、適用後も一覧は閉じません。
  - バーは**画面の右端**に半透明で表示され、**ドラッグで位置移動**できます。
  - **表示状態と位置は再ログイン後も維持**されます。
  - HUDは**街（都市）でのみ**表示されます。
  - Nexusメニューの Cupole Preset アイコンを**右クリック**してもHUDを開閉できます。
- **従来のクイック適用ポップアップを削除**（HUDに一本化）
- **プリセット編集ウィンドウの改善**
  - Set Name 保存時、上部の**タブ名が即座に反映**されます（ウィンドウを開き直す必要なし）。
  - 従来の「Clear」ボタンを**「Delete」に変更** — そのプリセットを完全に削除します。
  - 下部の所持クポル一覧の余白などレイアウトを整理しました。

### インストール方法
- 古い `cupole_manager` の ipf ファイルを削除して、このアドオンを入れてください。
- または addon manager から update してください。

### 使い方
- **Nexusメニューの Cupole Preset アイコンを左クリック** — プリセット編集ウィンドウを開く（プリセット1〜10の作成/保存）
- 右側の「Cupole Preset」バーの on/off ボタン（または メニューアイコンを**右クリック**）— プリセット一覧を開閉
- クポルの変更は街（都市）でのみ可能です。
